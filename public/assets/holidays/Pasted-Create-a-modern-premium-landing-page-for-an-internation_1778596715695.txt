Create a modern premium landing page for an international travel planning brand focused on LEAD GENERATION only, not online booking or transactions.

The goal of the website is to generate high-quality travel inquiry leads through forms and WhatsApp conversations.

BRAND POSITIONING:
A premium travel concierge that helps users plan unforgettable international experiences.

The brand should feel:

* modern
* premium
* trustworthy
* aspirational
* experience-led
* stress-free

NOT like:

* a cheap travel agency
* a crowded booking portal
* MakeMyTrip clone
* hotel aggregator

The emotional message:
“Experience the world, not just the landmarks.”

Subheadline:
“Flights, hotels, visas, and unforgettable local experiences — all seamlessly planned.”

TARGET AUDIENCE:

* Couples
* Honeymoon travelers
* Young professionals
* Families
* Premium experience seekers
* International first-time travelers

IMPORTANT:
This is NOT an end-to-end booking platform.
Users should NOT:

* book flights
* pay online
* select hotels
* transact

Instead, the website should:

* inspire users
* build trust
* showcase experiences
* collect leads
* encourage WhatsApp consultation
* push inquiry submissions

PRIMARY CTA:

* “Plan My Journey”
* “Get My Trip Plan”
* “Talk to a Travel Expert”
* “Get Custom Itinerary”

DESIGN STYLE:

* Luxury modern SaaS aesthetic
* Apple-inspired clean layout
* Cinematic travel visuals
* Soft gradients
* Minimal typography
* Large spacing
* Elegant cards
* Warm premium colors
* Mobile-first responsive
* Glassmorphism used subtly
* Smooth animations
* High-end travel brand feel

TECH STACK:

* React
* Tailwind CSS
* Framer Motion
* Reusable components
* Fully responsive
